# Compose Key for ChromeOS

This extension turns the right Alt key (or another key of your choice) into a
Compose key on several English keyboard layouts, including US, Canadian and
UK.

The key sequences follow
[Xlib](https://www.x.org/releases/current/doc/libX11/i18n/compose/en_US.UTF-8.html)
for the en_US.UTF-8 locale: every Xlib sequence that can be typed on a US
keyboard is built in. On top of that come emoticons (`:-)` → 🙂), arrows
(`-->` → ⟶), sequences from pointless-xcompose and kragen/xcompose, and
popular emoji by name (Compose `fire` → 🔥). Where sources disagree,
upstream's original table wins, then Xlib. A few
sequences were changed on purpose; `sequences/00-fixes.compose` and
`00-retired.compose` say which and why.

## Configuration

In Settings, under Keyboard and inputs, Input (the wording varies between
ChromeOS versions), add "Compose Key (US)" or the variant for your layout,
and switch to it. See https://support.google.com/chromebook/answer/1059492 for
how to get there.

The extension's Options page sets which key acts as Compose, and takes custom
XCompose sequences.

## How to use

1. Press and release the Compose key (right Alt by default).
2. Type one of the sequences below. The character appears when the
   sequence matches.
3. Escape cancels at any point.

### Holding vs. tapping Compose

You can tap Compose and then type the sequence, or hold Compose down while
typing it. Holding needs "Keep modifier" switched off in the options (the
default).

Known problem: while right Alt is held, ChromeOS acts on its own Alt shortcuts
before the extension sees the key, even though the extension suppresses it.
For example Alt + `-` minimizes the window, which also ends the composition.
Sequences containing such keys (`-`, `=`, `[`, `]`, and possibly digits) only
work in tap mode.

Some apps open their menu bar when Alt is pressed. For those, choose "Right
Alt or Right Control" as the Compose key in the options; either key then
works as Compose, and Right Control leaves the menu alone. Holding Right
Control may run into Ctrl shortcuts in the same way.

### Keys and names

After Compose, type a few keys or a name. Compose `" a` is ä, `o o` is °,
`fire` is 🔥; so are `yen` ¥, `times` ×, `delta` δ, `Delta` Δ, `pm` ±. Keys
or a name are typed as soon as nothing longer could mean something else;
otherwise the next key decides. Compose `pin` waits, as it could become
`pint`: Space types 📌 and a space, `t` makes it 🍺. Enter also completes a
name you have started, if only one fits: `multip`, Enter, is ×.

A few sequences are also the start of a name: Compose `m u` is µ, but
`multiplication` is ×. Such a sequence shows its character at once,
underlined, and the next key settles it: Compose `m u m` is µm. An option
types it by itself after a pause. It is off by default, because a pause in the
middle of a word then typed the wrong thing.

Anything that doesn't match stays underlined, with suggestions. Enter takes
the highlighted one (▸); with none highlighted, Enter, Space or punctuation
give exactly what you typed. A misspelt name is offered fixed (`fier`: 🔥),
and old habits from other tables are offered with their keys here (`c s`:
Compose `< s`, š). Backspace takes back one key.

If you are stuck, pause, and a list shows what can follow. Compose, then Tab,
or Compose twice, searches by name. Pick a row with the arrow keys (or Page
Up/Down) and Enter, or click it. Escape cancels. With left Alt as the Compose
key, release it before pressing Tab: ChromeOS keeps left Alt + Tab for
switching windows.

Accents are punctuation and work on either side of the letter: `" a` or
`a "` ä, `< c` or `c <` č, `U a` or `a (` ă, `: u` ü. Letters are never
accents. `*` before a letter is Greek: `* a` α, `* w` ω. Doubled, `_` and
`^` give sub- and superscripts: `_ _ i` ᵢ, `^ ^ n` ⁿ, `_ _ 4` ₄; for digits
one is enough, `_ 2` ₂ and `^ 2` ². If you prefer a sequence from another
table, add it to your own rules in the options; it behaves like a built-in
one.

## Event log

The options page shows the last 2000 events the extension has seen, so that a
problem can be looked at after it has happened: when each key came, what kind
of key it was (a character, a modifier, the Compose key, or the name of a key
such as Enter), how long the answer took, what the suggestion list showed,
focus changes, commits and their errors, and restarts of the service worker.
It does not record which keys were pressed or what was composed. It is always
on and kept only in memory, so a browser restart or a reload of the extension
clears it.

To record the keys themselves, run
`chrome.storage.local.set({debugLog: true})` in the service worker's console;
they are then logged to that console until it is set to `false`.

## Full list of built-in sequences

Sequences are grouped by where they come from. When two sources define the same
sequence, the earlier group wins: the original table first, then X11, then the
rest. A sequence that is complete but also starts a longer one (for example
`:-` and `:-)`) waits for the next key; release or press Compose again to get
the shorter one. "Compose Compose name" sequences need Compose pressed twice.
